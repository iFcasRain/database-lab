## 14. 一致性核对

| 核对项 | 结果 |
|---|---|
| 所有 `category_id` 都能在分类表找到 | 通过 |
| 所有商品都有当前库存记录 | 通过 |
| 所有订单的 `cashier_id` 都对应在职收银员 | 通过 |
| 订单 5001、5002 的会员存在，订单 5003 允许无会员 | 通过 |
| 每条订单明细引用的订单和商品均存在 | 通过 |
| 每张订单的明细金额之和等于订单原始金额 | 通过 |
| `paid_amount = original_amount - discount_amount` | 通过 |
| 积分增加为正、抵扣为负，变动后余额非负 | 通过 |
| 采购明细引用的采购单、商品均存在 | 通过 |
| 采购入库为正数且关联采购单，销售出库为负数且关联销售订单 | 通过 |
| 至少包含一个低库存商品、一个非会员订单和一个未审批采购单 | 通过 |
