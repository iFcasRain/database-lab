# 小卖部数据库 · 样例元组（第二周交付物）

> 与 `关系模式.md` 配套。样例满足以下约束：
> 1. 字段值符合类型与域（数量、金额、积分非负；`order_item.quantity > 0`）。
> 2. 主码、候选码不重复。
> 3. 外码都能在被引用表中找到对应记录。
> 4. 覆盖会员订单 / 非会员订单、在售 / 停用商品、低库存等不同业务情况。
> 5. 不使用真实个人手机号。

## 10. 一致性核对清单

- [x] 主码唯一：`product_id`、`member_id`、`employee_id`、`order_id` 无重复；`order_item` 联合主码 `(order_id, product_id)` 无重复。
- [x] 候选码唯一：`barcode`、`member_no`、`employee_no` 均无重复。
- [x] 外码可追溯：所有 `order_item.product_id/order_id`、`sales_order.employee_id/member_id`、`inventory_transaction.*`、`points_transaction.*` 均能在对应主表中找到记录（`member_id=NULL`、`related_order_id=NULL`、`order_id=NULL` 均为允许为空的合法情形）。
- [x] 金额对应：每笔订单 `total_amount` 与其 `order_item.line_amount` 之和相等。
- [x] 积分对应：`member.points_balance` 等于该会员最后一条 `points_transaction.balance_after`。
- [x] 覆盖会员订单（O000001）与非会员订单（O000002）。
- [x] 覆盖在售商品（P001、P002）与停用商品（P003）。
- [x] 覆盖低库存场景（P002 库存 8 < 预警 10）。
- [x] 覆盖待支付订单（O000003，不扣库存、不积积分）。
