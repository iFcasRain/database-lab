## 截图要求

1. 截图应同时包含正在执行的关键 SQL 或脚本名称、结果表格和成功消息。
2. 不要只截对象资源管理器而不截执行结果。
3. 错误截图应保留完整错误号和错误文字，方便定位问题。
4. 避免截入与实验无关的个人信息、密码或其他数据库内容。
5. 实际文件名可以调整，但应保持顺序清楚并能对应实验步骤。

若同类结果可以在一张图中清楚显示，可合并截图；不要为了减少数量而截掉结果标题、关键列或成功状态。
